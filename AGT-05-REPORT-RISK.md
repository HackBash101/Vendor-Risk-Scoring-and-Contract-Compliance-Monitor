# AGT-05 — Report + Risk Agent
> **ID:** AGT-05 | **Owner:** Dev 3 | **When:** Hour 4–5
> **File:** `backend/agents/report_risk_agent.py`
> **Layer:** Output | **Includes:** SLA Detection · AI Recommendations · PDF Generation

---

## Purpose
The final output agent. Aggregates scores from AGT-03 and AGT-04, computes the
overall weighted risk score, detects active SLA breaches, generates 3 AI-powered
recommendations via GPT-4o, and produces a professional 4-section PDF report.

---

## Architecture Position
```
AGT-03 Financial Score ─┐
AGT-04 Cyber Score      ├──► AGT-05 ─► PDF Report
AGT-02 SLA Records ─────┘    AGT-05 ─► Risk Score + Breach List
                              AGT-05 ─► AI Recommendations
```

## Overall Score Formula
```
overall_score = round(
    (financial_score × 0.30) +
    (cyber_score     × 0.30) +
    (sla_score       × 0.40)
)
Clamped to [0, 100]

Risk Level:
  > 70  →  "Low"
  >= 40  →  "Medium"
  < 40   →  "High"
```

## PDF Report Structure
```
Section 1 — Executive Summary

Section 3 — SLA Obligations

Section 4 — AI Recommendations
  3 numbered recommendations from GPT-4o
  Footer: "Generated by Vendor Risk Intelligence Platform"
```

```
Step 2 — Implement compute_overall_score(
    financial: int, cyber: int, sla: int
) -> int:
  weighted = round((financial * 0.30) + (cyber * 0.30) + (sla * 0.40))
  return max(0, min(100, weighted))

Step 3 — Implement get_risk_level(score: int) -> str:
  if score > 70: return "Low"
  if score >= 40: return "Medium"
  return "High"

Step 4 — Implement compute_sla_score(
    vendor_id: int, db: Session
) -> tuple[int, list[dict]]:
  """Compute SLA compliance score. Returns (score, breached_list)."""
  records = db.query(SLARecord).filter(
      SLARecord.vendor_id == vendor_id
  ).all()
  if not records:
      return (100, [])   # no obligations = full marks
  breached = [r for r in records if r.breached is True]
  sla_score = int(((len(records) - len(breached)) / len(records)) * 100)
  breached_list = [
      {
          "metric":    r.metric_name,
          "threshold": r.threshold_value,
          "unit":      r.threshold_unit,
          "severity":  r.breach_severity or "P3",
      }
      for r in breached
  ]
  return (sla_score, breached_list)

Step 5 — Implement generate_ai_recommendations(
    vendor_name, financial_score, cyber_score, sla_score, risk_level, breach_count
) -> list[str]:
  """Call GPT-4o for 3 recommendations. Use fallback if AI fails."""
  import json
  SYSTEM = (
      "You are a vendor risk advisor. "
      "Return ONLY a JSON array of exactly 3 strings. "
      "Each is one specific actionable recommendation. "
      "No markdown, no explanation, just the JSON array."
  )
  USER = (
      f"Vendor: {vendor_name}. Risk: {risk_level}. "
      f"Financial: {financial_score}/100. "
      f"Cyber: {cyber_score}/100. SLA: {sla_score}/100. "
      f"Breaches: {breach_count}. Give 3 recommendations."
  )
  try:
      from backend.services.openai_client import get_openai_client
      client = get_openai_client()
      resp = client.chat.completions.create(
          model="gpt-4o",
          messages=[{"role":"system","content":SYSTEM},{"role":"user","content":USER}],
          max_tokens=500, temperature=0.3,
      )
      return json.loads(resp.choices[0].message.content.strip())
  except Exception:
      # Fallback: choose by lowest-scoring dimension
      lowest = min(
          ("financial", financial_score),
          ("cyber", cyber_score),
          ("sla", sla_score),
          key=lambda x: x[1]
      )[0]
      return {
          "financial": [
              "Request latest audited financial statements",
              "Verify credit rating with Dun & Bradstreet",
              "Review payment terms and consider escrow options",
          ],
          "cyber": [
              "Request SOC 2 Type II audit report",
              "Require results of recent penetration test",
              "Enforce MFA and review access rights immediately",
          ],
          "sla": [
              "Schedule monthly SLA performance review",
              "Update contract KPI thresholds to reflect current performance",
              "Establish automated weekly SLA reporting cadence",
          ],
      }[lowest]
```

```python
cyber_score     × 0.30

> 70   →  Low
>= 40  →  Medium
```
